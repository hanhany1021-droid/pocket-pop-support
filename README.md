# Pocket Pop Support

Public privacy and support pages for Pocket Pop, an offline tactile bubble-wrap toy for iPhone.

## Live pages

- [Pocket Pop support site](https://hanhany1021-droid.github.io/pocket-pop-support/)
- [Privacy Policy](https://hanhany1021-droid.github.io/pocket-pop-support/privacy.html)
- [Support](https://hanhany1021-droid.github.io/pocket-pop-support/support.html)

The repository intentionally contains no application source code, credentials, analytics, customer records, or private release material. The Pocket Pop iOS source remains in a separate private repository.

## Repository structure

- `index.html`, `privacy.html`, `support.html`, `styles.css`: static GitHub Pages site
- `docs/PROJECT_CONTEXT.md`: purpose, boundaries, and maintenance contract
- `docs/ROADMAP.md`: verified baseline and next operational work
- `docs/DECISIONS.md`: append-only operational decisions
- `CONTRIBUTING.md`: change and validation rules

## Local validation

Open `index.html` in a browser and verify every internal link. Before publishing, confirm that the live privacy and support URLs return without authentication.

Start with [Project Context](docs/PROJECT_CONTEXT.md) before changing policy language or the support workflow.
