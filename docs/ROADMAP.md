# Roadmap

## Verified baseline

- [x] Static landing, privacy, and support pages exist.
- [x] Policy states the Pocket Pop 1.0 no-data boundary.
- [x] Support reports route to a public GitHub issue tracker.
- [x] Repository excludes the private iOS source and release credentials.

## Release readiness

- [ ] Verify all GitHub Pages URLs from a signed-out browser session.
- [ ] Add the live privacy and support URLs to App Store Connect.
- [ ] Recheck the pages whenever an App Store version changes privacy or permissions.

## Later operational improvements

- Add an issue template if unstructured reports become difficult to triage.
- Add another language only when there is a maintained review workflow for keeping policy meaning aligned.

## Non-goals

- Hosting the Pocket Pop application source.
- Collecting user analytics or support telemetry.
- Publishing private App Review correspondence or account-holder details.

Prioritize changes that keep policy claims accurate, pages accessible, and support intake safe.
